# Изображения страницы «Видеопродакшн»

Каждый слот на странице сначала ищет локальный файл `images/<slot>.jpg`, затем берёт
фото с Unsplash, затем с Picsum, и только потом показывает заглушку. Положите сюда
свои кадры и логотипы под этими именами — они подхватятся автоматически, в цвете
(фильтр grayscale убран со всех изображений).

| Файл | Где на странице |
| --- | --- |
| `cover-hero.jpg` | Обложка (00) |
| `work-0.jpg` … `work-8.jpg` | Лента работ (02): Art City, Apple, маркетплейсы, авиаинтерьеры, ICL, Технодор СК, НИИ «Турбокомпрессор», университет, Cattoi |
| `process-frame.jpg` | Процесс (03) |
| `bts-1.jpg`, `bts-2.jpg`, `bts-3.jpg` | За кадром (05), три полноэкранных слоя |
| `bts-s1.jpg` … `bts-s6.jpg` | За кадром (05), лента кадров внизу |
| `team-1.jpg` … `team-5.jpg` | Команда (07): Роман Лузянин, Ришат Нафиков, Наиль Иштыряков, Ильнар Тухватуллин, Ирина Журавлева |
| `case-a.jpg`, `case-b.jpg` | Кадры внутри открытого кейса |

Подойдут JPG/WebP любого размера; кадрирование — `object-fit: cover`.
